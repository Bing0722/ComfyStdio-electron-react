# ComfyStdio · Electron + React

ComfyUI 桌面管理界面，使用 Electron、React、TypeScript、electron-vite 和 Motion。

## 本地开发

使用 Node.js 22 LTS（至少 22.12）和 npm：

```sh
npm ci
npm run dev
```

`npm run typecheck` 检查类型，`npm test` 运行状态与目录扫描测试，`npm run build` 构建桌面应用。

[协作规范](AGENTS.md) · [设计与验收](DESIGN.md) · [模块结构](ARCHITECTURE.md)

## 一个 ComfyUI，一套内容

应用同时只管理一个 ComfyUI 工作目录。首次打开先选择并读取 ComfyUI，再进入启动、模型、插件和版本管理；不会预先把示例模型、插件当成本机内容。

- **启动**：显示当前程序、版本、模型目录和插件目录。更换目录会整体替换上下文，没有多实例列表。
- **模型管理**：读取当前目录的 `models`，显示实际文件名、类型、大小和路径。
- **插件**：读取当前目录的 `custom_nodes`，不执行 Python 或插件代码。目录存在不代表节点已成功加载。
- **版本**：切换与更新都针对同一份 ComfyUI，保留其模型与插件；不再提供多份安装和默认版本选择。
- **下载**：任务记录所属 ComfyUI 和目标模型目录。未完成任务、运行状态或版本操作会阻止更换目录。

### 真实读取与演示边界

本地目录读取已接入主进程，支持 ComfyUI 根目录及包含 `ComfyUI` 子目录的便携包。读取失败不展示旧内容；取消目录选择保留之前的上下文。重新读取会刷新版本、模型和插件。

真实启动、模型下载/删除、插件修改、Git 版本切换和远程更新尚未接入。本地扫描模式只读；演示下载不会写入磁盘或混入本地模型列表。点击“读取演示环境”可以体验启动、下载、插件操作及版本切换/更新，所有模拟数据都明确标识。

目录读取目前不解析 `extra_model_paths.yaml`，不跟随模型和插件符号链接，遇到这些情况显示提示；扫描有深度和文件数量上限。主题与液态效果持久化，业务上下文仅保留在当前界面会话，重新打开需重新读取。

## 界面

自定义标题栏移除默认 File/Edit 菜单。内容按卡片分区，支持浅色、深色和液态玻璃。Motion 负责导航、页面、按钮、菜单、弹窗、日志、列表、开关与进度动效，并尊重减少动态效果。
