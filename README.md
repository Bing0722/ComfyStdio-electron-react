## 本地开发

使用 Node.js 22 LTS（至少 22.12）和 npm：

```sh
npm ci
npm run dev
```

`npm run typecheck` 检查类型，`npm test` 运行状态与目录扫描测试，`npm run build` 构建桌面应用。

## 一个 ComfyUI，一套内容

应用同时只管理一个 ComfyUI 工作目录。首次打开先选择并读取 ComfyUI，再进入启动、模型、插件和版本管理；不会预先把示例模型、插件当成本机内容。

- **启动**：显示当前程序、版本、模型目录和插件目录。更换目录会整体替换上下文，没有多实例列表。
- **模型管理**：读取当前目录的 `models`，显示实际文件名、类型、大小和路径。
- **插件**：读取当前目录的 `custom_nodes`，不执行 Python 或插件代码。目录存在不代表节点已成功加载。
- **版本**：切换与更新都针对同一份 ComfyUI，保留其模型与插件；不再提供多份安装和默认版本选择。
- **下载**：任务记录所属 ComfyUI 和目标模型目录。未完成任务、运行状态或版本操作会阻止更换目录。

### 真实读取与演示边界

本地目录读取已接入主进程，支持 ComfyUI 根目录及包含 `ComfyUI` 子目录的便携包。读取失败不展示旧内容；取消目录选择保留之前的上下文。重新读取会刷新版本、模型和插件。

真实启动已接入；模型下载/删除、插件修改、Git 版本切换和远程更新尚未接入。本地扫描模式只读；演示下载不会写入磁盘或混入本地模型列表。点击“读取演示环境”可以体验启动、下载、插件操作及版本切换/更新，所有模拟数据都明确标识。

目录读取目前不解析 `extra_model_paths.yaml`，不跟随模型和插件符号链接，遇到这些情况显示提示；扫描有深度和文件数量上限。主题与液态效果持久化，业务上下文仅保留在当前界面会话，重新打开需重新读取。

## 界面

自定义标题栏移除默认 File/Edit 菜单。内容按卡片分区，支持浅色、深色和液态玻璃。Motion 负责导航、页面、按钮、菜单、弹窗、日志、列表、开关与进度动效，并尊重减少动态效果。

### 获取 ComfyUI 与设备信息

没有本地程序时，在启动页点击“获取 ComfyUI”，选择存放位置。需要系统已安装 Git 且可访问 GitHub；应用会创建新的 `ComfyUI` 文件夹并获取官方源码，自动读取其中的版本、模型和插件。已有同名目录不会覆盖；支持取消和失败后重试。Python、PyTorch 和运行依赖仍需另外配置，依赖配置完成后可真实启动。

侧栏“关于”无需读取程序即可使用，提供系统、CPU、内存、显卡、NVIDIA 驱动/显存、驱动支持的 CUDA 上限、CUDA 工具包以及系统 Python/Git 信息。工具缺失时明确显示未检测到；尚不检测 ComfyUI 独立虚拟环境的 PyTorch。

### 模块设置

设置已拆分为外观、文件夹管理、模型下载、插件安装与更新、ComfyUI 获取与更新。可以使用原生窗口选择当前 ComfyUI，并在系统文件管理器打开程序、模型和插件目录。

三类代理独立保存，支持 HTTP、HTTPS、SOCKS5、SOCKS5H；空地址表示直连。程序获取代理已经用于真实 Git 获取，模型下载和插件操作目前仍为演示，对应代理只保存配置。通知显示在窗口顶部中央。Windows 使用系统标题栏控件覆盖方案改善边框表现，仍需真机复验。

### 启动、日志与分类管理

本地 ComfyUI 支持真实启动、重启和关闭。默认“API 服务”模式仅监听 `127.0.0.1:8188`，禁用自动打开浏览器；“打开网页”在 `/system_stats` 响应后打开本地页面。两种模式使用同一服务，API 模式不屏蔽 ComfyUI 的网页路由。自动查找 `.venv`、`venv`、Windows 便携版 Python，或使用系统 Python；也可手动选择已安装依赖的 Python。当前不自动安装依赖，不负责连接或停止外部已运行的 ComfyUI。

“运行日志”独立页面保留本次应用会话最近 1000 条输出，可筛选信息、警告和异常，搜索或导出；重启服务保留历史。日志级别根据文本识别，不替代完整堆栈分析。退出应用会尝试停止本应用启动的进程树。

模型下载分为浏览、正在下载、已下载记录，仍为演示传输，不写入实际模型。模型管理按 Checkpoint、LoRA、VAE、ControlNet 和扫描到的其他目录分类，带数量与分类搜索。禁用插件使用独立徽标、侧边线和禁用说明，实际节点是否加载仍以运行日志为准。
