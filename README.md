# ComfyStdio · Electron + React

ComfyStdio 启动器的当前开发主线，使用 Electron、React、TypeScript 和 electron-vite。

## 本地开发

在本目录使用 Node.js 22 LTS（至少 22.12）和 npm。

```sh
npm ci
npm run dev
```

运行 `npm run typecheck` 检查类型，`npm test` 验证业务状态转换，`npm run build` 构建桌面应用代码。

`src/main/` 管理 Electron 窗口，`src/renderer/` 存放 React 界面。当前阶段使用自定义标题栏、简洁侧栏与卡片分区，用模拟数据演示启动、模型下载与管理、ComfyUI 版本管理和插件操作。

## 当前可用演示

六个页面已实现：启动、模型下载、模型管理、ComfyUI 版本、插件和设置。实例启动及下载队列通过定时状态变化演示，页面切换保留任务和筛选；下载完成后模型进入演示模型库。版本与插件支持会话内操作，删除、卸载和取消下载使用确认弹窗。

主题与液态效果保存在浏览器本地存储；其余数据刷新后恢复示例值。模型目录、并行任务和代理表单只演示配置及校验，不控制实际下载。所有示例路径、版本日期和传输指标均非真实环境信息。

### 窗口、材质与动效验证（2026-11-05）

- `npm run build`（含 TypeScript 检查）、`npm test` 四组状态回归测试和 `git diff --check` 通过。
- 在 Electron 中通过调试协议验证实例启动、停止、失败与重试；下载暂停、跨页保留、继续、失败重试及完成入库；版本安装与运行中切换保护、插件更新和实例隔离、移除确认弹窗。
- 验证下拉菜单方向键与 Enter 选择、Esc 关闭并返回焦点；浅色主题刷新后保留，液态效果开关可用。
- 检查 650×750 窄窗口和 1200×850 桌面截图，六个页面无横向溢出，侧栏底部设置与主题始终可见，底部主题菜单向上展开。验证减少动态效果媒体查询，样式已取消动画和过渡。
- 已接入 Motion 动画组件，覆盖导航、页面、按钮、菜单、弹窗、日志折叠、列表变化、开关与下载进度。液态模式使用大面积玻璃卡片与指针反光，普通模式保留实色卡片层次。
- macOS 实机检查应用菜单仅保留 ComfyStdio；窗口最小化、最大化/还原、关闭通过专用 preload 桥接并完成实测；Cmd+A 全选验证通过。Windows/Linux 的自定义窗口按钮已实现并通过类型检查，尚未在对应系统实测。
- 动画通过中间帧采样检查页面、日志与开关插值；快速切页、菜单退出禁用、弹窗焦点恢复与减少动态效果均纳入验证。
